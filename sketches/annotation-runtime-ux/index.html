Pageshelf annotation runtime · UX sketches

Separate selection actions from review actions.

Three disposable interaction models for the annotation runtime. The goal is IA clarity: selected text gets contextual actions; global review/export stops competing with the composer.

01

Selection-first contextual composer

Panel changes based on whether selection exists. Selection card appears only when relevant.

best incremental fit 02

Mode segmented panel

Explicit Annotate / Review / Export modes. Clean mental model, slightly more UI chrome.

clearest structure 03

Floating popover + review drawer

Selection composer near selected text; drawer only manages notes/export.

most app-like

My bias: 01 is safest to ship quickly. 03 is conceptually strongest, but browser selection positioning inside arbitrary artifacts is where bugs breed.
