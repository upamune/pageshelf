⌁ private shelf

one command, tiny shelf.

Start a local server, publish an HTML file, and hand back a clean URL. Use Tailscale when the artifact should be readable across your private network.

quick start
$ mise use -g github:upamune/pageshelf@latest
$ pageshelf serve --tailscale
$ pageshelf put --tailscale report.html

session: 20260510-0924-artifact-7k3p
url: http://example.tailnet.ts.net:8787/a/.../report.html
